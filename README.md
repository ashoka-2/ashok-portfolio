# Ashok Kumar — Portfolio

React + Vite portfolio with Tailwind CSS, GSAP, Lenis smooth scrolling, and a Matter.js interactive skills field.

## Run locally

```sh
npm install
npm run dev
```

## Update portfolio content

- `src/utils/profile.js` — bio, contact, education, skills, and interests
- `src/utils/projects.js` — project summaries, detail copy, stack, and links
- `src/utils/tech.js` — toolbox icons and documentation links
- `src/utils/site.js` — navigation and social links
- `src/utils/colors.js` and `src/index.css` — shared color names and design tokens

The React app is organized into `src/app`, reusable `src/components`, route-level `src/features`, and editable `src/utils` data. Project assets and supplied SVGs are in `public`.
